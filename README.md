## Як запустити агента

### Вимоги

- VS Code із GitHub Copilot Chat у режимі **Agent**;
- Node.js LTS;
- Git.

### Запуск

Надішли в Copilot Chat повідомлення:

```text
#file:.github/prompts/init.prompt.md виконай цей сценарій
```

Не використовуй слеш-команду `/init`, оскільки цю назву перехоплює вбудована команда Copilot.

### Очікуваний результат

Створено проєкт Hello World, build-артефакти `dist/` не комітяться, а команда `check` повертає `PASS`.

Повна інструкція, локальна перевірка та запуск зібраного проєкту описані в [`docs/usage.md`](docs/usage.md). Архітектура агента описана в [`docs/architecture.md`](docs/architecture.md).
